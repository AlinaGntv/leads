# Лиды

Мини-приложение для личного трекинга рассылок лидам: ежедневные касания, воронка конверсий и исходы лидов по месяцам.

## Как это устроено

Приложение состоит из двух вкладок сверху:

- **«Обычный»** — основной формат.
- **«Новый формат»** — отдельная статистика для нового подхода к общению с лидами.

У вкладок отдельные хранилища, поэтому данные не смешиваются.

### Обычный формат

- Цель дня: 45 касаний.
- Цель месяца: 1000 касаний.
- Клик по кружочку в блоке «45 касаний» отмечает прогресс за день (клик по уже закрашенному — снимает отметку). Кнопка «45» закрывает день целиком, «Сбросить день» обнуляет его.
- Воронка конверсий: **касания → ответы → тестовые → работа**. Счётчики «ответили / тестовые / работа» заполняются кнопками `+ / −` и не могут превышать предыдущий этап. Проценты — от предыдущего этапа и от касаний; в шапке воронки — итоговая конверсия «касание → работа».
- Исходы лидов: **проигнорировали 2-е / передали руководству / отказали** — счётчики `+ / −` с процентами от общего числа исходов.
- Счётчики «за месяц» и «в среднем» считаются из касаний по дням (без выходных).

### Новый формат

Исходы лидов (**проигнорировали 2-е / передали руководству / отказали**) в отдельном хранилище — для нового формата общения. Сверху — общее число исходов за месяц и доля переданных руководству.

### Хранение и сброс

- Данные сохраняются в `localStorage` браузера.
- Для каждого месяца создается отдельное хранилище.
- «Сбросить день», «Новый месяц» и «Сбросить месяц» обнуляют соответствующую статистику (касания, воронку и исходы).

## Публикация на GitHub Pages

Приложение доступно на [GitHub Pages](https://alinagntv.github.io/leads/) — без сервера и базы данных, всё работает в браузере.

При обновлении файлов `index.html`, `styles.css`, `script.js` увеличивай версию в параметрах подключения (например, `?v=8`), чтобы браузеры и CDN не отдавали закэшированные старые версии. Учти: GitHub Pages иногда собирает с задержкой — деплой (вкладка Actions) может провисесть в очереди несколько минут.
