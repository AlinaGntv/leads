# Лиды

Мини-приложение для личного трекинга рассылок лидам: ежедневные касания и воронка конверсий по месяцам.

## Как работает

- Цель дня: 45 касаний.
- Цель месяца: 1000 касаний.
- Клик по кружочку в блоке «45 касаний» отмечает прогресс за текущий день (клик по уже закрашенному — снимает отметку). Кнопка «45» закрывает день целиком, «Сбросить день» обнуляет его.
- Воронка конверсий: **касания → ответили → тестовые → работа**. Счётчики «ответили / тестовые / работа» заполняются кнопками `+ / −` и не могут превышать предыдущий этап.
- Проценты: каждый этап показывается в конверсии от предыдущего этапа и от общего числа касаний; в шапке воронки — итоговая конверсия «касание → работа».
- Счётчики «за месяц» и «в среднем» считаются из касаний по дням (без выходных).
- Данные сохраняются в `localStorage` браузера.
- Для каждого месяца создается отдельное хранилище; «Новый месяц» сбрасывает касания и воронку текущего месяца.

## Публикация на GitHub Pages

Приложение доступно на [GitHub Pages](https://alinagntv.github.io/leads/) — без сервера и базы данных, всё работает в браузере.

При обновлении файлов `index.html`, `styles.css`, `script.js` не забудь увеличить версию в параметрах подключения (`?v=3`), чтобы браузеры не отдавали закэшированные старые версии.
