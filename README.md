# Лиды

Мини-приложение для личного трекинга рассылок лидам: ежедневные касания и воронка конверсий по месяцам.

## Как работает

- Цель дня: 45 касаний.
- Цель месяца: 1000 касаний.
- Клик по кружочку в блоке «45 касаний» отмечает прогресс за день (клик по уже закрашенному — снимает отметку). Кнопка «45» закрывает день целиком, «Сбросить день» обнуляет его.
- Касания сверх нормы: после 45 можно добавлять ещё кнопками `+ / −` в блоке «Касания сверх нормы» — они идут в итог дня и в статистику месяца.
- Воронка конверсий: **касания → ответы → тестовые → работа**. Счётчики «ответили / тестовые / работа» заполняются кнопками `+ / −` и не могут превышать предыдущий этап. Проценты — от предыдущего этапа и от касаний; в шапке воронки — итоговая конверсия «касание → работа». Воронка считается **за текущий день**.
- Лог по дням: таблица в нижней части страницы показывает, сколько касаний (норма + сверх), ответов, тестовых и работ было отмечено в каждый день месяца; внизу — итог за месяц. Строка «Сегодня» подсвечивается.
- Переход к дате: клик по строке в логе, стрелки `‹ ›` или календарь (поле выбора даты) переключают экран «Сегодня» и блок «45 касаний» на выбранный день — видно и можно доправить любой день месяца. Кнопка «Сегодня» возвращает к текущему дню.
- Выбор месяца: панель сверху (стрелки `‹ ›` или поле выбора месяца) переключает весь вид на выбранный месяц — статистика «за месяц», карта месяца, лог и воронка за этот месяц. Данные каждого месяца хранятся отдельно.
- Воронка: переключатель **«День / Месяц»** — по дням (результаты указанного дня) или целиком за месяц (сумма по всем дням месяца — вся конверсия месяца). В режиме «Месяц» счётчики только для просмотра, правятся по дням.
- Счётчики «за месяц» и «в среднем» считаются из касаний по дням (без выходных).

## Хранение данных

- Данные сохраняются в `localStorage` браузера.
- Для каждого месяца создается отдельное хранилище (`leads-tracker:ГГГГ-ММ`), месяцы не смешиваются.
- «Новый месяц» обнуляет касания и воронку выбранного (или текущего) месяца.

## Публикация на GitHub Pages

Приложение доступно на [GitHub Pages](https://alinagntv.github.io/leads/) — без сервера и базы данных, всё работает в браузере.

При обновлении файлов `index.html`, `styles.css`, `script.js` увеличивай версию в параметрах подключения (например, `?v=13`), чтобы браузеры и CDN не отдавали закэшированные старые версии. Учти: GitHub Pages иногда собирает с задержкой — деплой (вкладка Actions) может провисесть в очереди несколько минут.
